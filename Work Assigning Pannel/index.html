☁️ Firebase Cloud Database Sync 🟡 Local Storage Mode

Connect your TaskFlow dashboard to a free Firebase Cloud Firestore database to enable real-time synchronization between Admin and Workers across any device or browser anywhere in the world!

📖 Quick 2-Minute Setup Guide
  1. Go to console.firebase.google.com and click Create a project.
  2. Under Build ➔ Firestore Database, click Create database (Start in Test mode).
  3. Go to Project Settings ⚙️ ➔ General ➔ Your apps, click the Web (</>) icon to register a Web App.
  4. Copy the 6 config keys shown in const firebaseConfig = { ... } and paste them in the fields above!
